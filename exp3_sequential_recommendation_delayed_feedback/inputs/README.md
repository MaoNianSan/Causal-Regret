# Required inputs

Place the following files under `inputs/KuaiRand-1K/data/`:

- `log_standard_4_08_to_4_21_1k.csv`
- `log_standard_4_22_to_5_08_1k.csv`
- `video_features_basic_1k.csv`

The random-exposure stream is not part of the primary Experiment 3 target.
Fast mode creates a deterministic fixture under `inputs/_fast_fixture/` only
when the original inputs are absent. Fixture results are never paper eligible.
