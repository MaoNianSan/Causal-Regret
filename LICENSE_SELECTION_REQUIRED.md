# License Selection Required

This repository currently has **no license**. A license was intentionally not
chosen during repository normalization, because selecting a license for
scientific code is an author decision that should not be made silently.

## Why this file exists

The repository is being prepared as a reproducibility companion for a paper.
A license affects how reviewers, future readers, and downstream users may
legally use and redistribute the code. Neither this repository nor its tooling
should pick one on behalf of the authors.

## Required decision

Before public release, the authors must decide and add one of:

- **MIT** — permissive, commonly used for research code;
- **BSD-3-Clause** — permissive, common in academia;
- **Apache-2.0** — permissive with explicit patent grant;
- **CC-BY-4.0** — attribution-only, sometimes preferred for artifacts that
  accompany a paper;
- any other license the authors and their institutions require.

## What to do

1. Choose a license (ideally with institutional/legal review).
2. Add the corresponding `LICENSE` file at the repository root.
3. Update the `License` section in `README.md`.
4. Remove or update this file to reflect the decision.

Note on data: raw external datasets (Criteo, KuaiRand-1K) are not part of
this repository and are governed by their own licenses; see `DATA.md`.
